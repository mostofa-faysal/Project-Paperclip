# Contributing to Project Paperclip

Thanks for your interest in contributing! This project is in early stages, so we value
feedback, issue reports, and small improvements that help establish the foundation.

## How to contribute
1. **Open an issue** to discuss your idea or report a bug.
2. **Fork the repo** and create a feature branch.
3. **Make focused changes** with clear, descriptive commits.
4. **Open a PR** with a summary and any relevant screenshots or logs.

## Development principles
- Keep data local by default.
- Design APIs with explicit permissions and transparency.
- Favor modular architecture and well-defined interfaces.

## Code of conduct
Be respectful and inclusive. We aim to build a welcoming community.
